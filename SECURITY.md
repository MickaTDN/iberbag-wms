# Segurança

Não publicar senhas, dados empresariais ou provas de exploração em issues públicas.
Comunicar ao proprietário por canal privado previamente acordado; confirmar no GitHub
se a comunicação privada de vulnerabilidades está ativa antes de enviar detalhes.

Correções em revisão e limitações: [guia de segurança](docs/CORRECOES_SEGURANCA_2026_10.md).
Só usar versões revistas e testadas, com Python 3.12 e locks. Não fazer deploy a partir
de artefactos de PRs desconhecidos. O executável DEMO anterior permanece suspenso; não
restaurar a quarentena nem criar exclusões de antivírus.
